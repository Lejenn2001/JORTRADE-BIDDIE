STAGE 3: Polygon Data Fetch (parallel for all candidate tickers)
Per ticker, three Polygon calls happen simultaneously:
fetchKeyLevels(ticker) — Polygon stocks data:
Daily bars (last 7 days) → prior day high/low/close/open, today's open/high/low
5-min intraday bars (today) → VWAP calculation: cumulative (H+L+C)/3 × volume / total volume
Pivot points calculated: Pivot = (PDH + PDL + PDC) / 3, R1 = 2×Pivot - PDL, S1 = 2×Pivot - PDH
Current price priority: Polygon WebSocket price → UW underlying_price → Polygon snapshot → last intraday bar close → prior day close
fetchRecentCandles(ticker, "1m", 10) — 1-minute bars for price action confirmation
fetchStructureCandles(ticker) — 15-minute bars over 5 days for ICT/SMC structure analysis
Finds swing highs/lows (3-bar pivot detection)
NOTE: These swing levels are used for Claude's ICT analysis but NOT for target generation on algo/whale signals

STAGE 10: Target Generation (Algo & Whale — NOT using swing data)
For CALLS — picks nearest level ABOVE current price:
Priority list (sorted by distance, takes closest 2):
VWAP (if above price)
Strike price (if above price)
Prior Day High (PDH)
R1 (first pivot resistance)
Pivot (if above price)
For PUTS — picks nearest level BELOW current price:
Priority list (sorted by distance, takes closest 2):
VWAP (if below price)
Strike price (if below price)
Prior Day Low (PDL)
S1 (first pivot support)
Pivot (if below price)
Fallback (no levels qualify): flat +2% / -2% from current price
Safety check: If target is in wrong direction (call target ≤ price, or put target ≥ price), reset to ±2%
⚠️ THIS IS THE WEAKNESS — No Polygon swing highs/lows used here. Hit rates: Strike=30%, Pivot=37.5%, Swing=86%

STAGE 12: Claude AI Evaluation (ICT/SMC analysis)
Top 15 candidates (sorted by confidence) are sent to Claude claude-sonnet-4-6 with:
All signal data (premium, aggression, strike, entry, category)
1-minute candle trend description
Full ICT/SMC market structure from fetchStructureCandles:
Multi-day trend (uptrend/downtrend/ranging)
Premium/Discount zone (is price above or below equilibrium)
Break of Structure (BOS) — trend continuation
Change of Character (CHoCH) — trend reversal
Fair Value Gaps (FVGs) — unfilled price imbalances
Inversed FVGs (IFVGs) — violated gaps that flipped meaning
Order Blocks — last opposing candle before impulse
Liquidity Levels — equal highs/lows where stops rest
Claude scores each signal:
Score
Criteria
8-10
Trend-aligned + Discount/Premium zone correct + multiple ICT confluences (BOS + FVG + OB)
5-8
Valid reversal (CHoCH confirmed) or FVG play with some confluence
3-5
Counter-trend without structure, or likely hedge
Claude returns per signal:
is_hedge: true/false
adjusted_confidence: 1-10
signal_quality: "strong" / "moderate" / "weak" / "hedge"
recommended_category: can override algo→whale or vice versa
Post-Claude filter: Must have is_hedge = false AND confidence ≥ 6 to survive
